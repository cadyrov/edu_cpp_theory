Доступные команды:

- `help` — показать команды;
- `look` — описать комнату, предметы, противников и выходы;
- `go <direction>` — перейти в соседнюю комнату;
- `take <item>` и `drop <item>` — управлять предметами;
- `inventory` и `stats` — показать состояние игрока;
- `use <item>` — применить предмет; в бою это тратит ход;
- `attack` — атаковать противника в текущем раунде;
- `run` — попытаться сбежать из боя; шанс зависит от сложности противника;
- `save <file>` и `load <file>` — сохранить или загрузить игру;
- `quit` — завершить игру.

При входе в комнату с живым противником игра переходит в режим боя. В каждом раунде игрок выбирает `attack`, `use <item>` или `run`. После `attack` и успешного `use` выживший противник отвечает. При неудачном побеге противник также атакует; успешный побег возвращает игрока в предыдущую комнату. Остальные игровые команды в режиме боя недоступны.

Победа: собрать три фрагмента печати и войти в финальную комнату. Поражение: здоровье игрока стало равно нулю. 
Игрок исследует комнаты, собирает три фрагмента печати, сражается с противниками и должен добраться до выхода живым. 

## Сборка и запуск

Из каталога `labirinth`:

```bash
cmake -S . -B build
cmake --build build
./build/labirinth
```

Запуск тестов после появления файлов в `tests`:

```bash
ctest --test-dir build --output-on-failure
```

При первой сборке тестов CMake автоматически загрузит GoogleTest, поэтому потребуется интернет.
