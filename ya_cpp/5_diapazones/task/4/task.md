# Сдвинутая координатная сетка

Сгенерируйте двумерную координатную сетку по значениям `start`, `stop` и `count`, затем сдвиньте каждую точку на заданный вектор.

```cpp
struct Shift {
    int x;
    int y;
};

struct Point {
    int x;
    int y;
};
```

Реализуйте функцию `get_shifted_grid`, которая:

- принимает координаты первой и последней точек одномерной оси;
- принимает количество точек на каждой оси;
- создаёт одинаковые равномерные последовательности для осей `x` и `y`;
- строит все комбинации координат этих осей;
- сдвигает каждую точку на переданный вектор;
- возвращает отображение элементов типа `Point`.

Для совместимости используйте адаптеры только из библиотеки range-v3.

## Подсказка

- Используйте `ranges::views::linear_distribute` для равномерных координат.
- Используйте `ranges::views::cartesian_product` для всех пар координат.
- Преобразуйте пары координат в `Point` через `ranges::views::transform`.
- Возвращаемое отображение не должно ссылаться на уничтоженные локальные объекты или параметры функции.
