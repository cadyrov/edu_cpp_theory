# Три крупнейшие транзакции категории

Немного усложним задачу про проекции.

```cpp
struct Transaction {
    double amount;
    std::string category;
};
```

Суммы транзакций хранятся в долларах. Нужно выбрать крупнейшие транзакции указанной категории и перевести их суммы в рубли по курсу `1 доллар = 100 рублей`.

Реализуйте функцию `get_top_transactions`, которая:

- принимает вектор транзакций и категорию;
- возвращает отображение из трёх крупнейших транзакций этой категории;
- если подходящих транзакций меньше трёх, возвращает их все;
- представляет суммы в результирующем отображении в рублях.

Допускается изменение порядка элементов исходного вектора.

## Подсказка

- Используйте `std::ranges::sort` и проекцию для сортировки по убыванию суммы.
- Используйте `std::views::filter` для выбора категории.
- Используйте `std::views::transform` для перевода долларов в рубли.
- Используйте `std::views::take(3)` для ограничения результата.
- Объедините отображения через оператор `|`.
- Учитывайте время жизни данных, захваченных возвращаемым отображением.
