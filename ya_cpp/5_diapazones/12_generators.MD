# 12. Генераторы

## Суть

Сопрограмма может приостановиться, сохранить состояние и позднее продолжить выполнение.

`std::generator` из C++23 использует сопрограмму для ленивой генерации последовательности:

```cpp
#include <generator>

std::generator<int> numbers() {
    co_yield 42;
    co_yield 100;
}

for (int value : numbers()) {
    // 42, 100
}
```

Вызов `numbers()` создаёт генератор, но не вычисляет сразу все элементы.

## Сопрограммы

Функция становится сопрограммой, если использует хотя бы одно ключевое слово:

- `co_yield` — выдаёт значение и приостанавливает выполнение;
- `co_await` — приостанавливается в ожидании другой операции;
- `co_return` — завершает сопрограмму.

Локальные переменные сохраняются между приостановками:

```cpp
std::generator<int> sequence() {
    int value = 1;

    while (value <= 3) {
        co_yield value;
        ++value;
    }
}
```

Сопрограмма не выполняется параллельно сама по себе. Она передаёт управление вызывающему коду и возобновляется по его запросу.

## Однопроходный диапазон

`std::generator` моделирует `input_range`, но не `forward_range`:

```cpp
auto generator = numbers();

static_assert(std::ranges::input_range<decltype(generator)>);
static_assert(!std::ranges::forward_range<decltype(generator)>);
```

Его значения читаются только одним проходом. Повторный вызов `begin()` для того же генератора приводит к неопределённому поведению.

Генератор нельзя копировать, но можно перемещать.

## Числа Фибоначчи

```cpp
std::generator<unsigned long long> fibonacci() {
    auto current = 0ULL;
    auto next = 1ULL;

    while (true) {
        co_yield current;

        const auto sum = current + next;
        if (sum < next) {
            co_return;
        }

        current = next;
        next = sum;
    }
}
```

Генератор комбинируется с адаптерами:

```cpp
auto firstEven = fibonacci()
    | std::views::filter([](auto value) {
          return value % 2 == 0;
      })
    | std::views::take(10);
```

Вычисляются только запрошенные значения.

## Рекурсивный генератор

`std::ranges::elements_of` позволяет передать наружу все элементы вложенного диапазона или генератора:

```cpp
template <class T>
struct Tree {
    T value;
    std::unique_ptr<Tree> left;
    std::unique_ptr<Tree> right;

    std::generator<const T&> inorder() const {
        if (left) {
            co_yield std::ranges::elements_of(left->inorder());
        }

        co_yield value;

        if (right) {
            co_yield std::ranges::elements_of(right->inorder());
        }
    }
};
```

Так естественно выражаются рекурсивные обходы деревьев и вложенных структур.

## Как хранится состояние

Компилятор создаёт кадр сопрограммы, содержащий:

- локальные переменные;
- параметры;
- текущую точку приостановки;
- служебное состояние;
- выданное значение.

При возобновлении выполнение продолжается после последнего `co_yield` или `co_await`.

## Подводные камни

### 1. Генератор однопроходный

Не сохраняй его как обычный повторно итерируемый контейнер и не запускай второй обход.

### 2. Следи за временем жизни ссылок

Генератор начинает выполнять тело не при вызове функции, а при начале обхода. Ссылочные параметры и захваты должны оставаться валидными всё это время.

```cpp
auto generator = makeGenerator(std::vector{1, 2, 3});
// опасно, если сопрограмма сохранила ссылку на временный vector
```

### 3. `co_yield` ссылки требует живой объект

При `std::generator<const T&>` исходный элемент должен существовать до использования выданной ссылки.

### 4. Возможны выделения памяти

Кадр сопрограммы может размещаться динамически. Генератор не гарантирует отсутствие аллокаций.

### 5. Исключение возникает во время обхода

Так как вычисления ленивые, ошибка внутри сопрограммы проявится при `begin()` или инкременте итератора.

### 6. Поддержка стандартной библиотеки

`std::generator` требует C++23 и заголовок `<generator>`, но доступность зависит от версии компилятора и стандартной библиотеки.

## Саммари

- Сопрограмма умеет приостанавливаться и сохранять локальное состояние.
- `co_yield` лениво выдаёт очередное значение.
- `std::generator` предоставляет интерфейс однопроходного диапазона.
- Генераторы комбинируются с `std::views`.
- `elements_of` поддерживает выдачу элементов вложенного генератора.
- Особое внимание нужно уделять одному проходу и времени жизни ссылок.
