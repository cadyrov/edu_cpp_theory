# 4. Фабрики диапазонов

## Суть

Фабрики диапазонов создают последовательности без исходного контейнера. Значения генерируются лениво во время обхода.

Основные фабрики:

- `std::views::iota` — последовательные значения;
- `std::views::repeat` — повторение одного значения.

## `std::views::iota`

`iota` создаёт полуинтервал: начальное значение входит в диапазон, конечное — нет.

```cpp
#include <print>
#include <ranges>

for (int i : std::views::iota(1, 5)) {
    std::print("{} ", i);
}
// 1 2 3 4
```

Диапазон не хранит четыре числа. Итератор хранит текущее значение и увеличивает его при переходе к следующему элементу.

## Итерация по индексам

```cpp
std::vector<std::string> names{"Ann", "Bob", "Sam"};

for (std::size_t i : std::views::iota(std::size_t{0}, names.size())) {
    std::println("{}: {}", i, names[i]);
}
```

Типы границ лучше согласовывать: здесь обе границы имеют тип `std::size_t`.

## Бесконечный `iota`

Если передать только начало, диапазон не имеет достижимого конца:

```cpp
auto firstFive = std::views::iota(10)
               | std::views::take(5);

// 10, 11, 12, 13, 14
```

Бесконечные фабрики обычно комбинируют с ограничивающим адаптером, например `take`.

## Пользовательский ограничитель

Конец не обязан иметь тот же тип, что и элементы. Достаточно возможности сравнить его с текущим значением.

```cpp
struct Bound {
    int value;

    friend bool operator==(int current, Bound bound) {
        return current == bound.value;
    }
};

auto numbers = std::views::iota(5, Bound{10});
// 5, 6, 7, 8, 9
```

## `std::views::repeat`

`repeat` создаёт диапазон из одинаковых значений. Он доступен начиная с C++23.

```cpp
using namespace std::literals;

for (auto value : std::views::repeat("C++"sv, 3)) {
    std::print("{} ", value);
}
// C++ C++ C++
```

```cpp
struct Point {
    int x;
    int y;
};

auto points = std::views::repeat(Point{1, 2}, 10);
```

Без количества повторений создаётся бесконечный диапазон:

```cpp
auto testData = std::views::repeat(42)
              | std::views::take(100);
```

## Подводные камни

### 1. Правая граница `iota` не входит в диапазон

Для чисел от `5` до `9` нужен `std::views::iota(5, 10)`.

### 2. Бесконечный диапазон нужно ограничивать

Обычный цикл по `iota(1)` или `repeat(value)` сам не завершится.

### 3. `repeat` требует C++23

В режиме C++20 `std::views::repeat` недоступен.

### 4. Значения не материализуются заранее

Фабрика не создаёт `std::vector`. Если нужен владеющий контейнер, элементы придётся скопировать в него отдельно.

### 5. Следи за переполнением

Очень долгий или ошибочно неограниченный `iota` целочисленного типа может дойти до переполнения.

## Саммари

- Фабрики создают ленивые диапазоны без исходного контейнера.
- `views::iota(begin, end)` генерирует значения из полуинтервала `[begin, end)`.
- Одноаргументный `iota` создаёт бесконечную последовательность.
- `views::repeat(value, count)` повторяет значение заданное число раз.
- `views::repeat` появился в C++23.
- Бесконечные диапазоны удобно ограничивать через `views::take`.
