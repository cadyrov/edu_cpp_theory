# 6. Адаптеры диапазонов

## Суть

Адаптеры позволяют лениво сегментировать, фильтровать, нумеровать и объединять последовательности.

В стандартной библиотеке многие из них появились только в C++23. В библиотеке range-v3 есть дополнительные адаптеры, которых пока нет в `std`.

## Сегментация

### `std::views::chunk`

Разбивает диапазон на непересекающиеся группы заданного размера:

```cpp
std::vector<int> values{1, 2, 3, 4, 5};

for (auto part : values | std::views::chunk(2)) {
    // {1, 2}, {3, 4}, {5}
}
```

Последняя группа может быть короче остальных. `chunk` доступен с C++23.

### `std::views::chunk_by`

Объединяет соседние элементы, пока бинарный предикат возвращает `true`:

```cpp
std::vector<double> temperatures{20.1, 20.3, 20.4, 22.0, 21.9};

auto periods = temperatures | std::views::chunk_by([](double a, double b) {
    return std::abs(b - a) < 0.5;
});
```

Адаптер группирует только соседние элементы, а не все одинаковые значения диапазона.

### `ranges::views::split_when`

Адаптер range-v3 разбивает последовательность по элементам, удовлетворяющим условию. Разделители в результат не входят.

```cpp
auto words = text | ranges::views::split_when([](char c) {
    return c == ' ' || c == '\n';
});
```

## Выбор элементов

`std::views::drop(N)` пропускает первые `N` элементов:

```cpp
auto tail = values | std::views::drop(1);
```

В range-v3 для удаления ровно первого элемента также есть `ranges::views::tail`.

`ranges::views::adjacent_filter` проверяет пары соседних элементов. Первый элемент включается автоматически, так как у него нет предыдущего:

```cpp
auto close = values
    | ranges::views::adjacent_filter([](int previous, int current) {
          return current - previous < 2;
      })
    | ranges::views::tail;
```

## Нумерация

`std::views::enumerate` добавляет к каждому элементу индекс:

```cpp
std::set<std::string> names{"Ann", "Bob"};

for (auto [index, name] : names | std::views::enumerate) {
    std::println("{}: {}", index, name);
}
```

Адаптер работает и с контейнерами без `operator[]`. Доступен с C++23.

## Объединение диапазонов

### `std::views::zip`

Объединяет элементы с одинаковыми позициями в tuple:

```cpp
std::vector<std::string> names{"Ann", "Bob"};
std::vector<int> scores{90, 75};

for (auto [name, score] : std::views::zip(names, scores)) {
    std::println("{}: {}", name, score);
}
```

Результат заканчивается вместе с самым коротким входным диапазоном.

### `std::views::cartesian_product`

Создаёт все возможные комбинации элементов:

```cpp
auto x = std::views::iota(1, 4);
auto y = std::views::iota(10, 12);

for (auto [a, b] : std::views::cartesian_product(x, y)) {
    // (1, 10), (1, 11), ..., (3, 11)
}
```

`zip` и `cartesian_product` доступны с C++23.

## Математические последовательности

`ranges::views::linear_distribute` из range-v3 создаёт заданное количество равномерно распределённых значений. Обе границы входят в результат:

```cpp
auto points = ranges::views::linear_distribute(0.0, 1.0, 5);
// 0.0, 0.25, 0.5, 0.75, 1.0
```

## Подводные камни

### 1. Проверяй версию стандарта

`chunk`, `chunk_by`, `enumerate`, `zip` и `cartesian_product` требуют C++23. `split_when`, `adjacent_filter`, `tail` и `linear_distribute` относятся к range-v3.

### 2. Адаптеры работают только с порядком следования

`chunk_by` не заменяет `group_by`: одинаковые несоседние элементы попадут в разные группы.

### 3. `zip` обрезает длинные диапазоны

Элементы после конца самого короткого диапазона не попадут в результат.

### 4. Декартово произведение быстро растёт

Для диапазонов размеров `N` и `M` оно содержит `N * M` комбинаций.

### 5. Вложенные диапазоны остаются невладеющими

Чанки и другие отображения зависят от времени жизни и валидности исходных данных.

### 6. Ссылки из `zip` могут изменять оригиналы

Элементы tuple часто являются ссылками. Изменение такого элемента способно изменить исходный контейнер.

## Саммари

- `chunk` делит данные на группы фиксированного размера.
- `chunk_by` группирует соседние элементы по отношению между ними.
- `drop` пропускает элементы в начале.
- `enumerate` добавляет индексы.
- `zip` объединяет элементы по позициям.
- `cartesian_product` создаёт все комбинации.
- Часть адаптеров требует C++23, часть доступна только в range-v3.
