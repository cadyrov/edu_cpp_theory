# Задания по диапазонам

Задания в каждой теме расположены от простых к сложным.

## 1. Предпосылки появления ranges

1. Найдите число в `std::vector<int>` сначала через `std::find`, затем через `std::ranges::find`.
2. Перепишите вызов `std::sort(begin, end)` на `std::ranges::sort(range)`.
3. Отфильтруйте чётные числа через `std::copy_if`, сохранив результат в отдельный вектор.
4. Добавьте к предыдущему решению `reserve` и объясните в комментарии, что он оптимизирует.
5. После `copy_if` возведите числа в квадрат через `std::transform`; посчитайте проходы и промежуточные контейнеры.
6. Перепишите предыдущую цепочку через `views::filter` и `views::transform` без промежуточного вектора.
7. Выберите первые пять положительных чисел классическими алгоритмами и покажите лишний обход входа.
8. Решите ту же задачу через `filter | take(5)` и посчитайте вызовы предиката.
9. Продемонстрируйте опасность пары итераторов от разных контейнеров, оставив некорректный вызов закомментированным.
10. Реализуйте обработку игроков «есть номер → вычислить счёт → взять первые 10» одним ленивым конвейером.

## 2. Диапазоны и отображения

1. Проверьте через `static_assert`, что `std::vector<int>` удовлетворяет `std::ranges::range`.
2. Проверьте концепт `range` для массива, `std::string_view`, указателя и `std::initializer_list`.
3. Напишите функцию печати, принимающую `std::ranges::range auto&&`.
4. Получите `begin`, `end`, `iterator_t` и `sentinel_t` произвольного диапазона.
5. Создайте `std::ranges::ref_view` для именованного вектора и измените через него элемент.
6. Используйте `std::views::all` для lvalue-вектора и временного вектора; сравните типы обёрток.
7. Создайте `subrange` из середины строки и выведите его без копирования.
8. Реализуйте sentinel, завершающий диапазон при встрече заданного значения.
9. Адаптируйте диапазон с разными типами начала и конца через `views::common` для `std::accumulate`.
10. Реализуйте функцию, принимающую любой `input_range` и суммирующую элементы до пользовательского sentinel.

## 3. Проекции

1. Отсортируйте `Person` по возрасту через лямбда-компаратор.
2. Перепишите сортировку через проекцию `&Person::age`.
3. Найдите объект с заданным `id` через `std::ranges::find` и проекцию.
4. Найдите минимальную транзакцию по `amount` через `ranges::min_element`.
5. Проверьте наличие несовершеннолетнего через `ranges::any_of` и проекцию возраста.
6. Отсортируйте объекты по убыванию поля, передав компаратор и проекцию.
7. Отсортируйте людей по паре `(age, name)` через проекцию-лямбду.
8. Реализуйте `call_callback` через `std::invoke` для функции, функтора и метода класса.
9. Используйте `std::invoke` с указателем на поле и убедитесь, что результат является ссылкой.
10. Постройте индекс элементов: сортируйте индексы по проекции в значения исходного контейнера.

## 4. Фабрики диапазонов

1. Выведите числа от `1` до `9` через `std::views::iota`.
2. Создайте диапазон индексов вектора с согласованным типом `std::size_t`.
3. Посчитайте сумму чисел из конечного `iota` через ranges-алгоритм.
4. Создайте бесконечный `iota` и безопасно ограничьте его через `take(10)`.
5. Получите первые десять чётных чисел из бесконечного `iota`.
6. Создайте 20 одинаковых объектов `Point` через `views::repeat`.
7. Сгенерируйте сто тестовых значений через бесконечный `repeat | take(100)`.
8. Реализуйте пользовательскую границу для `iota`, сравнимую с текущим значением.
9. Постройте таблицу квадратов для чисел `[1, 100)` без исходного контейнера.
10. Создайте ленивую бесконечную последовательность арифметической прогрессии из `iota | transform` и ограничьте результат.

## 5. Базовые адаптеры

1. Оставьте в векторе только положительные числа через `views::filter`.
2. Получите квадраты всех элементов через `views::transform`.
3. Выберите чётные числа и возведите их в квадрат через pipe-синтаксис.
4. Запишите ту же композицию функциональным синтаксисом.
5. Возьмите первые три элемента конечного диапазона через `views::take`.
6. Посчитайте вызовы предиката и преобразования до и после обхода view.
7. Обойдите один view дважды и покажите повторное выполнение преобразования.
8. Сравните результат цепочек `filter | transform` и `transform | filter`.
9. Найдите первые пять чисел, квадрат которых оканчивается цифрой `6`, используя бесконечный диапазон.
10. Реализуйте функцию, возвращающую безопасный ленивый pipeline над переданным внешним диапазоном.

## 7. `view_interface` и пользовательские отображения

1. Создайте минимальный view с `begin()` и `end()` поверх пары указателей.

3. Реализуйте итератор, бесконечно возвращающий одно заданное значение.
4. Создайте `repeat_view(value)` с `std::unreachable_sentinel`.
5. Добавьте конечную форму `repeat_view(value, count)`.

7. Создайте `cycle_view`, корректно обрабатывающий пустой диапазон.
8. Добавьте адаптер `cycle`, принимающий `viewable_range` и использующий `views::all`.

10. Реализуйте бесконечный `random_view` с воспроизводимой последовательностью по одинаковому `seed`.
