# 3. Проекции

## Суть

Проекция — вызываемый объект, который алгоритм применяет к элементу перед сравнением или другой операцией.

Она позволяет работать с отдельным полем объекта без многословной лямбды и не изменяет исходный элемент.

```cpp
struct Person {
    std::string name;
    int age;
};

std::vector<Person> people{
    {"Alice", 30},
    {"Bob", 25},
    {"Charlie", 35}
};

std::ranges::sort(people, {}, &Person::age);
```

Алгоритм получает `age` каждого человека и сравнивает уже эти значения. `{}` означает компаратор по умолчанию — `std::ranges::less`.

## Callable-сущности

Проекцией может быть любая сущность, которую умеет вызывать `std::invoke`:

- функция или указатель на неё;
- лямбда или другой функтор;
- указатель на нестатический метод;
- указатель на нестатическое поле.

```cpp
#include <functional>

struct Data {
    int value = 42;
    int doubled() const { return value * 2; }
};

Data data;

int value = std::invoke(&Data::value, data);       // 42
int result = std::invoke(&Data::doubled, data);    // 84
```

`std::invoke` предоставляет единый синтаксис вызова для всех Callable-сущностей.

## Проекция-лямбда

Лямбда удобна, если одного поля недостаточно:

```cpp
std::ranges::sort(people, {}, [](const Person& person) {
    return std::tuple{person.age, person.name};
});
```

Сначала люди сортируются по возрасту, при равенстве — по имени.

## Проекции в других алгоритмах

Проекции поддерживает большинство ranges-алгоритмов.

```cpp
auto it = std::ranges::find(people, 25, &Person::age);

bool hasMinor = std::ranges::any_of(
    people,
    [](int age) { return age < 18; },
    &Person::age
);
```

В `find` значение сравнивается с результатом проекции. В `any_of` предикат получает уже `age`, а не объект `Person`.

## Проекция по умолчанию

Если проекция не передана, используется `std::identity` — объект, возвращающий аргумент без изменений.

```cpp
std::vector<int> values{3, 1, 2};
std::ranges::sort(values); // сравниваются сами элементы
```

## Подводные камни

### 1. Компаратор идёт перед проекцией

```cpp
std::ranges::sort(people, std::ranges::greater{}, &Person::age);
```

Этот код сортирует по возрасту по убыванию.

### 2. Проекция может вызываться много раз

Не добавляй в неё побочные эффекты и тяжёлые вычисления: алгоритм не обязан вызывать её ровно один раз для каждого элемента.

### 3. Проекция не меняет тип элементов контейнера

Она только предоставляет алгоритму другое представление элемента. После сортировки `people` всё ещё содержит объекты `Person`.

### 4. Указатель на поле подходит не всегда

Для вычисляемого значения, нескольких полей или вложенной логики понадобится функция или лямбда.

### 5. Требования проверяются после проекции

Результат проекции должен подходить компаратору или предикату. Иначе ограничение алгоритма не будет выполнено и код не скомпилируется.

## Саммари

- Проекция преобразует представление элемента перед его обработкой.
- Проекцией может быть любая Callable-сущность.
- `std::invoke` единообразно вызывает функции, функторы, методы и поля.
- `&Type::field` кратко задаёт обработку по одному полю.
- `std::identity` используется как проекция по умолчанию.
- Проекция может вызываться многократно, поэтому должна быть дешёвой и без побочных эффектов.
