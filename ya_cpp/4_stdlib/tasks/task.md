# Задания по массивам и std::array

## 1. Создание массива

Создайте `std::array<int, 5>` со значениями `1, 2, 3, 4, 5`.

Выведите:

- первый элемент;
- последний элемент;
- размер массива через `size()`.

## 2. Обход и изменение

Создайте `std::array<int, 4>` со значениями `1, 2, 3, 4`.

Умножьте каждый элемент на `10` через range-based for.

Выведите результат.

## 3. operator[] и at()

Создайте `std::array<int, 3>`.

Покажите разницу:

- прочитайте корректный индекс через `operator[]`;
- прочитайте корректный индекс через `at()`;
- обработайте исключение `std::out_of_range` при обращении через `at()` за границы.

## 4. Инициализация

Создайте три массива:

- `std::array<int, 5> a = {1, 2, 3}`;
- `std::array<int, 5> b = {};`;
- `std::array c = {1, 2, 3, 4};`.

Выведите их размеры и элементы.

Проверьте, какие значения получили неуказанные элементы в `a` и `b`.

## 5. Передача в функцию

Напишите функцию:

```cpp
void Print(const std::array<int, 3>& values);
```

Она должна вывести все элементы.

Затем напишите функцию для C-style API:

```cpp
void PrintRaw(const int* data, std::size_t size);
```

Вызовите ее для `std::array` через `data()` и `size()`.

## 6. C-style массив и потеря размера

Создайте C-style массив:

```cpp
int values[] = {1, 2, 3, 4};
```

Напишите функцию:

```cpp
void BadPrint(int values[]);
```

Проверьте внутри нее, что `sizeof(values)` дает размер указателя, а не массива.

Затем исправьте код через явную передачу размера.

## 7. Присваивание и копирование

Создайте два `std::array<int, 3>`.

Присвойте один другому через `=`.

Затем попробуйте сделать то же самое с C-style массивами и оставьте ошибочную строку закомментированной.

Объясните в комментарии, почему `std::array` присваивается, а C-style массив нет.

## 8. Поиск, сортировка и binary search

Создайте:

```cpp
std::array<int, 6> values = {5, 1, 4, 2, 6, 3};
```

Сделайте:

- поиск числа `4` через `std::find`;
- сортировку через `std::sort`;
- поиск числа `4` через `std::lower_bound`.

Выведите найденный индекс в обоих поисках.

## 9. Тип без конструктора по умолчанию

Создайте тип:

```cpp
struct User {
    explicit User(int id);
    int id;
};
```

Покажите, что `std::array<User, 3> users;` не компилируется.

Оставьте эту строку закомментированной.

Затем создайте корректный массив с явной инициализацией трех элементов.

## 10. Мини-класс IPv4

Реализуйте класс:

```cpp
struct IPv4 {
    std::array<std::uint8_t, 4> data = {};
};
```

Напишите функции:

```cpp
bool TryFromString(std::string_view text, IPv4* ipv4);
std::string ToString(const IPv4& ipv4);
```

Требования:

- строка должна иметь формат `A.B.C.D`;
- частей должно быть ровно `4`;
- каждая часть должна быть числом от `0` до `255`;
- при ошибке функция должна вернуть `false`;
- `ToString` должна вернуть строку в том же формате.

Используйте `std::array`, `std::string_view`, `std::from_chars` и `std::to_string`.
