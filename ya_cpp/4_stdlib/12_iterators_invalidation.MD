# 12. Итераторы и инвалидация

## Суть

Инвалидация означает, что итератор, ссылка или указатель больше нельзя использовать.

Контейнер изменился, и старый доступ мог стать опасным.

## Пример 1: vector и реаллокация

```cpp
std::vector<int> values{1, 2, 3};

auto it = values.begin();

values.push_back(4); // может быть реаллокация

// *it использовать опасно
```

Если буфер переехал, старый итератор указывает в старую память.

## Пример 2: erase возвращает новый итератор

```cpp
std::vector<int> values{1, 2, 3, 4};

for (auto it = values.begin(); it != values.end();) {
    if (*it % 2 == 0) {
        it = values.erase(it);
    } else {
        ++it;
    }
}
```

После `erase` нужно использовать возвращенный итератор.

## Пример 3: list

```cpp
std::list<int> values{1, 2, 3};

auto first = values.begin();
auto second = std::next(first);

values.erase(second);

std::cout << *first << '\n'; // ok
```

У `list` удаление одного элемента обычно не ломает итераторы на другие элементы.

## Подводные камни

## 1. Нельзя увеличивать стертый итератор

```cpp
for (auto it = values.begin(); it != values.end(); ++it) {
    if (*it == 0) {
        values.erase(it); // после этого ++it опасен
    }
}
```

Нужно писать `it = values.erase(it)`.

## 2. reserve может инвалидировать

```cpp
auto it = values.begin();

values.reserve(1000);

// it может стать невалидным
```

Если память была перевыделена, старые итераторы больше не годятся.

## 3. end() тоже может инвалидироваться

```cpp
auto last = values.end();
values.push_back(42);
```

Старый `end()` после изменения контейнера лучше не использовать.

## 4. Правила зависят от контейнера

У `vector`, `deque`, `list`, `map` разные правила инвалидации.

Их нужно знать для выбранного контейнера.

## Саммари

- Инвалидация делает старые итераторы, ссылки или указатели непригодными.
- У `vector` рост может переехать в новую память.
- После `erase` используй возвращенный итератор.
- У `list` итераторы на другие элементы обычно стабильнее.
- Правила инвалидации зависят от контейнера и операции.
