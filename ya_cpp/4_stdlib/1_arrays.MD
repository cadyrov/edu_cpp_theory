# 1. Массивы

## Суть

Массив - это последовательность элементов одного типа, лежащих подряд в памяти.

В C++ чаще всего встречаются три варианта:

- сырой массив `T[N]`;
- стандартный массив `std::array<T, N>`;
- динамический массив внутри `std::vector<T>`.

В этой теме главное: понять фиксированный размер, непрерывную память и отличие массива от указателя.

## Сырой массив

```cpp
int a[3] = {10, 20, 30};

std::cout << a[0] << '\n';
std::cout << a[1] << '\n';
std::cout << a[2] << '\n';
```

Индексация начинается с нуля.

```cpp
a[0] // первый элемент
a[1] // второй элемент
a[2] // третий элемент
```

Размер сырого массива фиксирован во время компиляции.

```cpp
int a[3]; // всегда 3 int
```

## std::array

`std::array` - это безопасная обертка над массивом фиксированного размера.

Элементы лежат непрерывно в памяти. Сам объект обычно находится там же, где объявлен: в автоматической памяти для локальной переменной или в статической области для глобальной/static-переменной.

`std::array` не делает динамических аллокаций. Это полезно, когда нужно заранее контролировать объем памяти: например, во встраиваемых системах, буферах фиксированного размера и коде, где нежелательны аллокации во время выполнения.

```cpp
#include <array>
#include <iostream>

int main() {
    std::array<int, 3> a = {10, 20, 30};

    std::cout << a[0] << '\n';
    std::cout << a.size() << '\n';
}
```

Вывод:

```text
10
3
```

У `std::array` есть методы контейнера:

- `size()`;
- `max_size()`;
- `empty()`;
- `data()`;
- `front()`;
- `back()`;
- `begin()`;
- `end()`.

`data()` возвращает указатель на внутренний массив.

```cpp
std::array<int, 3> a = {10, 20, 30};

int* p = a.data();
```

`std::array` не превращается в `int*` автоматически.

```cpp
void foo(int* p) {}

std::array<int, 3> a = {1, 2, 3};

// foo(a);        // ошибка
foo(a.data());    // ok
```

Размер можно вывести из списка инициализации:

```cpp
std::array a = {1, 2, 3};
```

Здесь тип будет `std::array<int, 3>`.

## Пример 1: проход по массиву

```cpp
#include <array>
#include <iostream>

int main() {
    std::array<int, 4> values = {1, 2, 3, 4};

    for (int value : values) {
        std::cout << value << '\n';
    }
}
```

Такой цикл не требует вручную считать индексы.

## Пример 2: изменение элементов

```cpp
#include <array>
#include <iostream>

int main() {
    std::array<int, 3> values = {1, 2, 3};

    for (int& value : values) {
        value *= 10;
    }

    for (int value : values) {
        std::cout << value << ' ';
    }
}
```

Вывод:

```text
10 20 30
```

Важно: `int& value` нужен, чтобы менять элементы внутри массива.

## Пример 3: передача в функцию

```cpp
#include <array>
#include <iostream>

void print(const std::array<int, 3>& values) {
    for (int value : values) {
        std::cout << value << ' ';
    }
}

int main() {
    std::array<int, 3> values = {10, 20, 30};
    print(values);
}
```

`const std::array<int, 3>&` означает:

- функция не копирует массив;
- функция не меняет элементы;
- размер `3` является частью типа.

## Массив и указатель

Сырой массив часто неявно превращается в указатель на первый элемент.

```cpp
void print(int* p) {
    std::cout << p[0] << '\n';
}

int main() {
    int a[3] = {10, 20, 30};
    print(a);
}
```

Проблема: функция `print` не знает размер массива.

Лучше явно передавать размер:

```cpp
void print(const int* p, std::size_t size) {
    for (std::size_t i = 0; i < size; ++i) {
        std::cout << p[i] << ' ';
    }
}
```

Или использовать `std::array`, если размер известен заранее.

Для C-style-массивов также есть `std::begin`, `std::end` и `std::size`.

```cpp
int a[] = {1, 2, 3};

for (auto it = std::begin(a); it != std::end(a); ++it) {
    std::cout << *it << ' ';
}
```

Но у самого C-style-массива методов нет.

## Доступ к элементам

```cpp
std::array<int, 3> a = {10, 20, 30};

std::cout << a[1] << '\n';
std::cout << a.at(1) << '\n';
```

`operator[]` не проверяет границы.

`at()` проверяет и бросает `std::out_of_range`.

## Инициализация

`std::array` поддерживает агрегатную инициализацию.

```cpp
std::array<int, 5> a = {1, 2, 3};
```

Если элементов меньше, оставшиеся инициализируются значениями по умолчанию.

```cpp
std::array<int, 5> a = {1, 2, 3}; // 1 2 3 0 0
```

Если элементов больше размера, будет ошибка компиляции.

```cpp
// std::array<int, 2> a = {1, 2, 3}; // ошибка
```

Без инициализации простые типы могут содержать мусор.

```cpp
std::array<int, 2> a;      // значения не заданы
std::array<int, 2> b = {}; // 0 0
```

## Стоимость операций

- доступ по индексу - `O(1)`;
- запись в уже существующий элемент - `O(1)`;
- присваивание одного `std::array` другому - `O(N)`;
- линейный поиск через `std::find` - `O(N)`;
- сортировка через `std::sort` - `O(NlogN)`;
- бинарный поиск по отсортированному массиву - `O(logN)`.

Добавления в конец у `std::array` нет: размер и вместимость фиксированы.

```cpp
std::array<int, 3> a = {3, 1, 2};

std::sort(a.begin(), a.end());

auto it = std::lower_bound(a.begin(), a.end(), 2);
```

`std::array` имеет итераторы произвольного доступа, поэтому подходит для `std::sort`.

## Подводные камни

## 1. Выход за границы

```cpp
int a[3] = {10, 20, 30};

std::cout << a[3]; // undefined behavior
```

Последний корректный индекс здесь - `2`.

## 2. Потеря размера

```cpp
void foo(int a[]) {
    // a на самом деле int*
}
```

В параметре функции `int a[]` превращается в `int*`.

Размер массива теряется.

## 3. Копирование сырого массива

```cpp
int a[3] = {1, 2, 3};
int b[3];

// b = a; ошибка
```

Сырые массивы нельзя присваивать друг другу напрямую.

`std::array` можно:

```cpp
std::array<int, 3> a = {1, 2, 3};
std::array<int, 3> b;

b = a;
```

## 4. Большой массив на стеке

```cpp
void foo() {
    int data[10'000'000]; // риск переполнить стек
}
```

Большие массивы лучше хранить в `std::vector`.

## 5. Размер std::array - часть типа

```cpp
std::array<int, 3> a = {1, 2, 3};
std::array<int, 4> b = {1, 2, 3, 4};

// a = b; ошибка: разные типы
```

`std::array<int, 3>` и `std::array<int, 4>` - разные типы.

## 6. at() и operator[]

```cpp
std::array<int, 3> a = {1, 2, 3};

a[3] = 10;    // undefined behavior
a.at(3) = 10; // исключение std::out_of_range
```

`at()` безопаснее, но чуть тяжелее.

## 7. Тип должен уметь создаваться по умолчанию

```cpp
struct User {
    explicit User(int id) {}
};

std::array<User, 3> users; // ошибка
```

При таком объявлении нужно создать все элементы, а у `User` нет конструктора по умолчанию.

Можно явно инициализировать элементы:

```cpp
std::array<User, 3> users = {User(1), User(2), User(3)};
```

## 8. move и swap не бесплатные

```cpp
std::array<std::string, 100> a;
std::array<std::string, 100> b = std::move(a);
```

Перемещается каждый элемент.

Для `std::array` перемещение и `swap` стоят `O(N)`, а не `O(1)`.

## Когда что использовать

- `std::array` - фиксированный небольшой размер, известный заранее.
- `std::vector` - размер может меняться или данные большие.
- сырой массив - низкоуровневый код, C API, учебные примеры.

## Саммари

- Массив хранит элементы одного типа подряд в памяти.
- Индексы начинаются с нуля.
- Сырой массив `T[N]` имеет фиксированный размер.
- `std::array<T, N>` - удобная стандартная обертка над фиксированным массивом.
- `std::array` хранит элементы непрерывно и не делает динамических аллокаций.
- Размер и вместимость `std::array` фиксированы на этапе компиляции.
- `std::array` полезен, когда нужно контролировать память и избегать аллокаций во время выполнения.
- Сырой массив при передаче в функцию часто превращается в указатель.
- `std::array` не decay-ится в сырой указатель автоматически.
- `data()` дает указатель на внутренние данные.
- `at()` проверяет границы, `[]` - нет.
- Указатель не хранит размер массива.
- Выход за границы массива - undefined behavior.
- Доступ к элементу и запись в существующий элемент стоят `O(1)`.
- `std::array` поддерживает присваивание, но оно стоит `O(N)`.
- `std::array` можно сортировать стандартными алгоритмами.
- `move` и `swap` для `std::array` стоят `O(N)`.
- Добавлять элементы в конец нельзя: для этого нужен контейнер с изменяемым размером.
- Большие массивы лучше не класть на стек.
- Если размер должен меняться, нужен `std::vector`.
