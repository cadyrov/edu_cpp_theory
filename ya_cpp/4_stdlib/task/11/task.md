Перед вами реализация алгоритма линейного поиска, который часто используется в нетривиальных алгоритмах. 

Функция принимает на вход шаблонный параметр — контейнер, т. е. потенциально может работать с любым контейнером, но её реализация требует обращаться к элементам по индексу. Например для контейнера std::vector такая функция будет работать, a для std::list уже нет — он не поддерживает обращение по индексу.

```cpp
template <class Container, class T>
std::optional<size_t> find(const Container& c, const T& t) {
  for (size_t i = 0; i < c.size(): ++i) {
    if (c[i] == t) {
      return i;
    }
  }
  return std::nullopt;
} 
```

Скопируйте код ниже к себе и реализуйте функцию find для итераторов. При этом помните:
Итераторы бывают разных типов, поэтому разумно использовать шаблонные аргументы.
Как правило, в алгоритмах стандартной библиотеки в функции передаётся пара итераторов — начало и конец — и возвращается итератор.

```cpp
/* ваш код*/
/* ваш код*/ find(/* ваш код*/) {
  /* ваш код*/
} 
```
- Помните, что каждый итератор обладает методом operator++.
