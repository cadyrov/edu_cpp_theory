Реализуйте простой менеджер непрерывной памяти.

Менеджер управляет диапазоном адресов `[0, size)`. В каждый момент времени этот диапазон разбит на непересекающиеся блоки. Каждый блок задаётся полуинтервалом `[left, right)` и может быть свободным или занятым.

Менеджер поддерживает две операции:

- `acquire(size)` — найти первый свободный блок размером не меньше `size` и занять его начало;
- `release(blockId)` — освободить ранее выделенный блок.

Для хранения всех блоков используйте `std::list`: при разделении и объединении блоков потребуется вставлять и удалять элементы, не инвалидируя итераторы на остальные элементы списка.

## Выделение памяти

Метод `acquire(size)` просматривает блоки слева направо и выбирает первый свободный блок, для которого `right - left >= size`.

- Если размер найденного блока равен `size`, блок нужно просто пометить занятым.
- Если найденный блок больше, перед ним нужно вставить новый занятый блок `[left, left + size)`, а левую границу свободного блока сдвинуть на `size`.
- Если подходящего блока нет, метод возвращает `std::nullopt`.

Каждому занятому блоку присваивается уникальный `BlockId`. В `used_` нужно сохранить соответствие между этим идентификатором и итератором на блок в списке.

## Освобождение памяти

Метод `release(blockId)` находит занятый блок в `used_`, удаляет запись о нём и помечает блок свободным. После этого блок нужно объединить со свободным соседом слева, затем — со свободным соседом справа.

Объединение двух соседних свободных блоков должно оставлять в списке один блок, покрывающий весь их общий диапазон.

Можно считать, что:

- конструктор получает положительный размер памяти;
- `acquire` получает положительный размер;
- в `release` передаётся идентификатор блока, который сейчас занят.

```cpp
using BlockId = int;

        int left;
        int right;
        bool free = true;
    };

public:
    explicit MemoryManager(int size) {
        // ваш код здесь
    }

    std::optional<BlockId> acquire(int size) {
        // ваш код здесь
    }

    void release(BlockId blockId) {
        // ваш код здесь
    }

private:
    std::list<Block> blocks_;
    std::unordered_map<BlockId, std::list<Block>::iterator> used_;
    BlockId nextBlockId_ = 0;
};
```
