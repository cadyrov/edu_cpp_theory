Представьте, что вы реализуете менеджер памяти, которая представлена непересекающимися блоками и хранится у менеджера. Менеджер имеет два метода: 
- acquire(count) — ищет первый свободный блок нужного размера и выделяет (занимает) его;
- release(block) — освобождает блок.

В начале менеджер инициализируется одним свободным блоком размера, а затем в произвольном порядке приходит множество запросов acquire/release. Ваш код должен находить свободный блок, если такой имеется, и выделять его, а иначе — возвращать std::nullopt.

Выделение блока происходит так:
- Перед найденным блоком вставляется новый блок нужного размера.
- У найденного блока сдвигается левая граница на размер.
- ID блока возвращается как результат. ID блока выбирается как индекс блока в массиве занятых (std::vector), чтобы при освобождении можно было легко найти этот блок.

Освобождение блока происходит так:
- В массиве занятых блоков находится итератор на блок по ID блока.
- С помощью итератора блок помечается как свободный.
- Блок объединяется с соседними свободными блоками слева и справа. Для объединения нужно удалить один блок и сдвинуть границу соседнего.

Для хранения блоков используйте std::list, чтобы эффективно вставлять и удалять элементы. При этом:

Каждый элемент списка должен хранить информацию: левая граница, правая граница, и признак занятости.
Менеджер должен корректно обрабатывать вызовы в произвольном порядке, включая многократное выделение и освобождение.

```cpp
using BlockId = int;

class MemoryManager {
    struct Block {
        int left;
        int right;
        bool free = true;
    };

public:
    explicit MemoryManager(int size) { 
        // ваш код здесь
    }
    std::optional<BlockId> acquire(int size) {
        // ваш код здесь
    }
    void release(BlockId blockId) {
        // ваш код здесь
    }
private:
    std::list<Block> blocks_;
    std::unordered_map<BlockId, std::list<Block>::iterator> used_;
}; 
```

- При освобождении блока сначала поменяйте блок на позиции blockId с последним в векторе, а затем удалите последний элемент.
- При освобождении блока объедините его с блоком слева, если тот свободен и образует с текущим непрерывную область. Аналогично с блоком справа.
