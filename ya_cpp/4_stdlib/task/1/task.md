Представьте, что вы пишете свой класс, который моделирует IPv4-адрес — набор из четырёх чисел от 0 до 255, разделённых символом ".", например, "192.168.277.1". Очень часто с IP-адресами приходится работать, как со строками, но это очень неэффективно с точки зрения затрат памяти. 

Строка адреса имеет неопределённую длину (может быть 0.0.0.0 или 255.255.255.255), которая занимает минимум 7 байт. Но адрес можно представить в виде четырёх чисел типа uint8_t. Такое внутреннее представление будет иметь минимально возможную фиксированную длину. 

Класс, который вы пишете, — идеальный кандидат для использования std::array в качестве внутреннего представления IP-адреса.

Реализуйте функцию TryFromString, которая создаёт объект из валидной строки вида "192.168.277.1", и функцию ToString, которая возвращает валидную строку адреса.

```cpp
struct IPv4 {
    std::array<uint8_t, 4> data = {};
};

bool TryFromString(const std::string_view buf, IPv4* ipv4) {
    /* Ваш код здесь */
}

std::string ToString(const IPv4& ipv4) {
    /* Ваш код здесь */
} 
```

- В TryFromString построчно ищите идущие подряд символы '.' и приводите подстроки между ними в числа. Вам помогут функции std::string::find и std::from_chars.
- В ToString используйте функцию std::to_string(num).
