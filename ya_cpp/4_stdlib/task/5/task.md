Представьте, что вам необходимо реализовать планировщик процессов. Процесс представлен структурой Process с виртуальными часами — они показывают, сколько процессорного времени в секундах занимает исполнение процесса, и его приоритет от 0 до 10. 

Планировщик хранит две очереди процессов: с высоким и низким приоритетом — и исполняет процессы сначала с высоким приоритетом, затем с низким. На исполнение процесса на каждой итерации планировщик даёт 2 секунды.

Скопируйте код ниже к себе и организуйте две очереди процессов с помощью std::deque:
первая очередь — для процессов с высоким приоритетом (priority > 5);
вторая — для процессов с низким приоритетом (priority ≤ 5).

```cpp

struct Process {
    int id;
    int priority;
    int ticks;
};

class Scheduler {
public:
    void run();
};

int main() {
    Scheduler scheduler{{1, 1, 2}, {2, 6, 10}, {3, 3, 2}};
    scheduler.run();
    return 0;
} 
```

- Чтобы организовать очерель, добавляйте элементы в конец и удаляйте из начала std::deque.
