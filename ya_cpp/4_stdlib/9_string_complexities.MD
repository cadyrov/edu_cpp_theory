# 9. Сложности строк

## Суть

`std::string` похож на `std::vector<char>`.

У нее есть размер, вместимость и возможные реаллокации.

## Основные операции

- доступ по индексу - `O(1)`;
- добавление в конец - амортизированно `O(1)`;
- вставка в середину - `O(n)`;
- удаление из середины - `O(n)`;
- поиск подстроки - зависит от реализации, обычно не дешевле линейного прохода.

## Пример 1: добавление

```cpp
std::string s;

for (int i = 0; i < 1000; ++i) {
    s.push_back('x');
}
```

Добавление в конец обычно быстрое.

## Пример 2: reserve

```cpp
std::string s;
s.reserve(1000);

for (int i = 0; i < 1000; ++i) {
    s += "x";
}
```

`reserve` уменьшает количество выделений памяти.

## Пример 3: дорогая конкатенация

```cpp
std::string result;

for (const std::string& part : parts) {
    result += part;
}
```

Без `reserve` строка может много раз перевыделять память.

## Подводные камни

## 1. Вставка в начало дорогая

```cpp
s.insert(s.begin(), 'x');
```

Все символы придется сдвигать.

## 2. substr копирует

```cpp
auto part = s.substr(10, 5);
```

Это новая строка и новая память.

## 3. Малые строки могут не выделять память

Многие реализации используют small string optimization.

Короткая строка может храниться внутри самого объекта `std::string`.

На это нельзя завязывать логику программы.

## 4. Указатели инвалидируются

```cpp
const char* p = s.data();

s += "text";

// p может стать невалидным
```

При реаллокации буфер переезжает.

## Саммари

- `std::string` имеет размер и вместимость.
- Индексация - `O(1)`.
- Добавление в конец - амортизированно `O(1)`.
- Вставка и удаление в середине - `O(n)`.
- `reserve` полезен при сборке большой строки.
- `substr` копирует.
- Изменение строки может инвалидировать указатели на ее данные.
