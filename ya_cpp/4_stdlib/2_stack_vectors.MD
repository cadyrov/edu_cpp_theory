# 2. Стековые векторы

## Суть

Стековый вектор - это массив с логическим размером.

Память уже выделена заранее, а программа отдельно хранит, сколько элементов сейчас используется.

```cpp
std::array<int, 10> data;
std::size_t size = 0;
```

`data.size()` - вместимость.

`size` - текущее количество элементов.

## Пример 1: добавление

```cpp
#include <array>
#include <iostream>

int main() {
    std::array<int, 5> data;
    std::size_t size = 0;

    data[size++] = 10;
    data[size++] = 20;
    data[size++] = 30;

    for (std::size_t i = 0; i < size; ++i) {
        std::cout << data[i] << ' ';
    }
}
```

Вывод:

```text
10 20 30
```

## Пример 2: проверка вместимости

```cpp
bool push(std::array<int, 3>& data, std::size_t& size, int value) {
    if (size == data.size()) {
        return false;
    }

    data[size++] = value;
    return true;
}
```

Перед записью нужно проверить, что место еще есть.

## Пример 3: удаление последнего

```cpp
bool pop(std::size_t& size) {
    if (size == 0) {
        return false;
    }

    --size;
    return true;
}
```

Для простых типов можно просто уменьшить логический размер.

## Подводные камни

## 1. Путаница размера и вместимости

```cpp
std::array<int, 10> data;
std::size_t size = 3;
```

В массиве есть место под `10` элементов, но реально заполнены только `3`.

## 2. Запись за пределы

```cpp
data[size++] = value; // опасно без проверки size < data.size()
```

Если места нет, будет выход за границы.

## 3. Чтение неинициализированных элементов

```cpp
for (int value : data) {
    std::cout << value << ' ';
}
```

Такой цикл пройдет по всей вместимости, а не по логическому размеру.

## 4. Нет автоматического роста

Стековый вектор не увеличивает буфер сам.

Если нужен рост, обычно берут `std::vector`.

## Саммари

- Стековый вектор = буфер + логический размер.
- Вместимость фиксирована заранее.
- Перед добавлением нужна проверка места.
- Итерироваться нужно до логического размера.
- Для растущего контейнера нужен `std::vector`.
