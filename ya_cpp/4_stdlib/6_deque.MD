# 6. Двусторонние очереди

## Суть

`std::deque` - очередь с двумя концами.

Она позволяет эффективно добавлять и удалять элементы и в начале, и в конце.

```cpp
#include <deque>

std::deque<int> values;
```

Название читается как double-ended queue.

## Устройство

`std::deque` хранит элементы не одним большим непрерывным массивом, как `std::vector`.

Обычно данные лежат в отдельных непрерывных блоках памяти.

Отдельно хранится массив указателей на эти блоки.

Идея:

- внутри блока элементы лежат подряд;
- блоки могут добавляться в начало и конец;
- доступ по индексу вычисляет номер блока и позицию внутри блока.

Поэтому у `deque` есть доступ по индексу за `O(1)`, но нет единого непрерывного буфера для всех элементов.

## Пример 1: оба конца

```cpp
#include <deque>
#include <iostream>

int main() {
    std::deque<int> values;

    values.push_back(20);
    values.push_front(10);
    values.push_back(30);

    for (int value : values) {
        std::cout << value << ' ';
    }
}
```

Вывод:

```text
10 20 30
```

## Пример 2: удаление

```cpp
std::deque<int> values{10, 20, 30};

values.pop_front();
values.pop_back();
```

Останется один элемент: `20`.

## Пример 3: доступ по индексу

```cpp
std::deque<int> values{10, 20, 30};

std::cout << values[1] << '\n';
```

Доступ по индексу есть и стоит `O(1)`.

Но элементы не обязаны лежать одним непрерывным блоком.

## Пример 4: стек

```cpp
bool is_valid(std::string_view s) {
    std::deque<char> stack;

    for (char c : s) {
        if (c == '(') {
            stack.push_back(c);
        } else if (stack.empty()) {
            return false;
        } else {
            stack.pop_back();
        }
    }

    return stack.empty();
}
```

Здесь `deque` используется как стек: добавление и удаление идут с конца.

## Пример 5: очередь

```cpp
std::deque<std::string> history;

history.push_back("open");
history.push_back("save");

std::string first = history.front();
history.pop_front();
```

Здесь `deque` используется как очередь: добавляем в конец, удаляем из начала.

## Стоимость операций

- доступ по индексу - `O(1)`;
- `push_front` - амортизированно `O(1)`;
- `push_back` - амортизированно `O(1)`;
- `pop_front` - `O(1)`;
- `pop_back` - `O(1)`;
- вставка в середину - `O(N)`;
- удаление из середины - `O(N)`;
- линейный поиск - `O(N)`.

Если места в текущем блоке нет, `deque` выделяет новый блок.

Если в массиве указателей на блоки нет места, он может быть перевыделен с запасом.

## Инвалидация

Добавление и удаление в начале или конце обычно не перемещает сами существующие элементы.

Поэтому ссылки и указатели на остальные элементы часто остаются пригодными.

Но итераторы могут инвалидироваться, потому что внутренняя карта блоков могла измениться.

Правила инвалидации у `deque` сложнее, чем у `vector`.

## Подводные камни

## 1. Это не vector

```cpp
// values.data() // у deque нет такого интерфейса как у vector
```

`std::deque` не дает один указатель на весь массив элементов.

Если нужен непрерывный буфер, нужен `std::vector`.

## 2. Вставка в середину все еще дорогая

```cpp
values.insert(values.begin() + 2, 42);
```

`deque` хорош для концов, а не для середины.

## 3. Нет дешевого C API

Так как нет единого непрерывного массива, `deque` нельзя просто передать в C API через `data()` и `size()`.

## 4. Индексация O(1), но тяжелее vector

Для индекса нужно найти блок и смещение внутри блока.

Это `O(1)`, но обычно с большим постоянным множителем, чем у `vector`.

## 5. Инвалидация сложнее

Операции с `deque` могут инвалидировать итераторы.

Ссылки и указатели ведут себя стабильнее при работе с концами, но правила лучше проверять для конкретной операции.

## Когда использовать

- часто нужен `push_front`;
- часто нужен `pop_front`;
- нужен доступ по индексу;
- нужно моделировать очередь;
- не нужен единый непрерывный буфер.

## Саммари

- `std::deque` - очередь с двумя концами.
- Элементы хранятся в отдельных непрерывных блоках.
- Блоки управляются через массив указателей.
- Доступ по индексу стоит `O(1)`.
- `push_front` и `push_back` стоят амортизированно `O(1)`.
- `pop_front` и `pop_back` стоят `O(1)`.
- Вставка и удаление из середины стоят `O(N)`.
- `deque` удобно использовать как стек или очередь.
- У `deque` нет единого непрерывного буфера как у `vector`.
- Для передачи в C API обычно нужен `std::vector`, а не `std::deque`.
