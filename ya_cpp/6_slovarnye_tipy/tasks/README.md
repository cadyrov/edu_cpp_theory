# Задания по словарным типам

## 1. Пары и кортежи

1. Создайте `std::pair<std::string, double>` с названием и ценой товара; выведите `first` и `second`.
2. Реализуйте функцию разбора числа, возвращающую `std::pair<int, bool>` со значением и статусом.
3. Измените оба элемента пары через структурную привязку по ссылке.
4. Создайте запись пользователя `std::tuple<int, std::string, double>` и получите поля через `std::get<Index>`.
5. Получите элементы кортежа через `std::get<Type>`, затем добавьте повторяющийся тип и исправьте код.
6. Верните из функции имя объекта и три координаты в кортеже; распакуйте результат структурной привязкой.
7. Сохраните аргументы функции вычисления объёма в кортеже и вызовите её через `std::apply`.
8. Отсортируйте вектор пар `{очки, имя}` и проверьте лексикографический порядок.
9. Напишите `print_tuple`, печатающую элементы `std::tuple` и `std::pair` через `std::apply`.
10. Замените кортеж результата расчёта заказа структурой с именованными полями.

## 2. Метапрограммирование с `std::tuple`

1. Проверьте `std::tuple_size_v` и типы `std::tuple_element_t` для кортежа из трёх элементов.
2. Напишите `Sum`, складывающую произвольное число аргументов с помощью fold expression.
3. Напишите `PrintAll`, печатающую пачку аргументов через свёртку по оператору `,`.
4. Реализуйте `getFirstElements<N>` с помощью `std::make_index_sequence<N>`.
5. Реализуйте `reverse`, создающую кортеж с обратным порядком элементов.
6. Реализуйте `lastN<N>`, возвращающую последние `N` элементов кортежа.
7. Напишите `transform_tuple`, применяющую функцию к каждому элементу кортежа.
8. Реализуйте `value_or_empty`, возвращающую одноэлементный либо пустой кортеж по предикату типа.
9. Реализуйте `filter_tuple<std::is_arithmetic>`, используя `std::tuple_cat`.
10. Проверьте функции `getFirstElements`, `reverse` и `filter_tuple` через `static_assert`.

## 3. `std::optional`

1. Реализуйте поиск первого чётного числа с возвратом `std::optional<int>`.
2. Напишите `ParseInt`, возвращающую `std::nullopt` при некорректной строке.
3. Перепишите класс с объектом и отдельным флагом готовности через `std::optional`.
4. Покажите разницу между отсутствующей строкой и присутствующей пустой строкой.
5. Продемонстрируйте безопасный доступ через `value()` и предварительно проверенные `*` и `->`.
6. Используйте `value_or` для lvalue- и rvalue-`optional<std::string>` и отследите копирования и перемещения.
7. Создайте необязательный объект без конструктора по умолчанию через `emplace`.
8. Сравните пустые и непустые `optional<int>` между собой и с обычным `int`.
9. Реализуйте ленивую загрузку значения, выполняемую только при первом обращении.
10. Верните `optional` с некопируемым и неперемещаемым объектом через `std::in_place`.

## 4. Выражение семантики значения в типе

1. Для пяти интерфейсов выберите между `std::optional<T>`, `T*`, `T&`, `std::reference_wrapper<T>` и `gsl::not_null<T*>`; объясните выбор комментарием.
2. Перепишите функцию с необязательным выходным параметром так, чтобы она возвращала `std::optional<T>`.
3. Оберните результат C API в функцию, возвращающую проверенный `gsl::not_null<T*>`.
4. Замените обязательный сырой указатель в параметре функции на `gsl::not_null<T*>`.
5. Создайте `std::vector<std::reference_wrapper<int>>` и измените через него исходные элементы.
6. Отсортируйте обёртки-ссылки по значениям, не меняя порядок исходного контейнера.
7. Продемонстрируйте разницу между присваиванием через `T&` и переназначением `reference_wrapper<T>`.
8. Найдите и исправьте висячий `reference_wrapper`, созданный из элемента изменяемого вектора.
9. Замените пару «указатель + размер» на `std::span<T>` и сравните контракт с `not_null<T*>`.
10. Спроектируйте API с необязательным владельцем, обязательным внешним объектом и контейнером внешних ссылок, выбрав отдельный тип для каждого поля.

## 5. Монадические операции `std::optional`

1. Преобразуйте `optional<int>` в `optional<std::string>` через `transform`.
2. Соедините функции `ParseInt` и `ValidatePositive`, возвращающие `optional`, через `and_then`.
3. Добавьте запасную загрузку данных через `or_else`.
4. Перепишите цепочку вложенных проверок `if (!value)` через монадические методы.
5. Найдите и исправьте ошибочный `transform`, создающий `optional<optional<T>>`.
6. Покажите, что `or_else` и последующие операции не вызываются на неподходящих ветках.
7. Сравните передачу тяжёлого значения по `const&` и перемещение из rvalue-`optional`.
8. Замените дорогой `value_or(CreateDefault())` ленивым восстановлением через `or_else`.
9. Обработайте HTTP-запрос цепочкой `and_then`, `transform` и `value_or`.
10. В C++26 соберите значения из диапазона `optional<T>` через `views::join`; добавьте эквивалент для C++23 через `filter` и `transform`.

## 6. Тип-сумма `std::variant`

1. Создайте `variant<int, double, std::string>` и последовательно сохраните каждый тип.
2. Получите активное значение через `get`, `get_if` и `holds_alternative`; сравните поведение.
3. Реализуйте печать вариантов через проверки типа и индекс.
4. Добавьте `std::monostate` и обработайте явное пустое состояние.
5. Создайте `std::vector<int>` внутри `variant` через `in_place_type`, затем замените его через `emplace`.
6. Создайте `variant` с повторяющимся `std::string` и работайте с ним по индексам.
7. Замените ручную структуру `union + enum` на `std::variant`.
8. Сравните размер `variant` с размерами его альтернатив и объясните влияние индекса и выравнивания.
9. Создайте тип, бросающий исключение при перемещении, и исследуйте `valueless_by_exception`.
10. Для задачи с закрытым набором фигур сравните решение через виртуальную иерархию и через `std::variant`.
